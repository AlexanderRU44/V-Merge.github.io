# 🚀 V-Merge

**V-Merge** — это связка «веб-витрина + автопарсер» для работы с конфигурационными ссылками (VLESS, VMess, Trojan, Hysteria2, Shadowsocks). Сайт показывает список собранных конфигов, а GitHub Actions автоматически собирает, чистит, определяет страну и обновляет файл подписки каждые 6 часов — без вашего участия.

---

## 🌐 Что где

| Компонент | Назначение | URL |
|---|---|---|
| **Сайт** (`index.html`) | Просмотр конфигов, фильтры, сортировка, копирование | `https://alexanderru44.github.io/V-Merge.github.io/` |
| **Подписка** (`output/merged.txt`) | Готовый список ссылок для клиентов | `https://raw.githubusercontent.com/AlexanderRU44/V-Merge.github.io/main/output/merged.txt` |
| **Подписка в base64** (`output/merged.base64.txt`) | То же, но в формате base64 для некоторых клиентов | `https://raw.githubusercontent.com/AlexanderRU44/V-Merge.github.io/main/output/merged.base64.txt` |
| **Кэш стран** (`scripts/geo_cache.json`) | Словарь `host → код страны`, пополняется автоматически | `https://raw.githubusercontent.com/AlexanderRU44/V-Merge.github.io/main/scripts/geo_cache.json` |

## ✨ Возможности

### Автосборка (`scripts/merge.py`)
- **Объединение источников** — берёт все URL из `scripts/sources.txt`, скачивает и объединяет в один список.
- **Авто-декодирование** — если источник отдаёт base64-подписку, скрипт её декодирует.
- **Дедупликация** — удаляет дубликаты по ключу `(тип, адрес, порт)`.
- **Определение страны** — для каждого нового хоста спрашивает `ip-api.com` и записывает результат в `scripts/geo_cache.json`. Значения `"XX"` перезапрашиваются при каждом прогоне, пока не определятся.
- **Переименование** — жёстко перезаписывает имя каждой ссылки в формат `🇩🇪 DE #N`. Старые названия из источников стираются.
- **Два формата вывода** — `merged.txt` (plain) и `merged.base64.txt` (base64).

### Сайт (`index.html`)
- **Две колонки:** список конфигов слева, таблица параметров справа.
- **Колонка «Страна»** с флагами и кодами (🇷🇺 RU, 🇩🇪 DE и т.д.).
- **Фильтры** по стране и типу, поиск по адресу.
- **Сортировка** по любой колонке — клик по заголовку.
- **Счётчик** `видимых / всего` в шапке.
- **Кнопки:** обновить, копировать (только видимые), скачать TXT (только видимые).
- **Клик по строке таблицы** — подсветка соответствующего конфига в списке.
- **Автозагрузка** при открытии страницы.

### Автоматизация (`.github/workflows/update.yml`)
- **Cron** — запуск каждые 6 часов (`0 */6 * * *`).
- **Ручной запуск** — кнопка «Run workflow» во вкладке Actions.
- **Автокоммит** — обновлённые `merged.txt`, `merged.base64.txt` и `geo_cache.json` пушатся обратно в репозиторий.
